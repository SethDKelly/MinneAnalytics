# 001-F Evidence — Surviving Operational-Principle Baseline

Status: **Complete for 001-F**  
Concept model maturity: **v0 — discovery**  
Purpose: define the candidate set that has survived purpose discovery, criteria review, and operational-principle falsification and may enter 001-G consolidation.

## 1. Interpretation

This baseline supersedes the 001-E candidate list for 001-G.

It still does **not** make these concepts canonical.

A surviving candidate now has:

- a supported purpose;
- a plausible independent boundary;
- acceptable specificity/completeness/genericity;
- a natural archetypal operational principle.

001-G must decide which candidates are ready to exit discovery into formal concept specification and which remain provisional/deferred.

## 3. Candidate removed during 001-F

**Disposition:** demoted to future concept signal / externally or locally sourced operational fact.

**Reason:** no current concept-local lifecycle survives evidence discipline.

- Owning registration/cancellation actions would invent behavior.

Future discovery may revive Registration or Enrollment if MinneAnalytics gains a real user-facing registration lifecycle or materially richer registration-state management.

## 6. Operational-principle quality summary

### Particularly strong separations

Operational-principle work strengthens these independent boundaries:

- Proposal ↔ Revision;
- Evaluation ↔ Controlled Disclosure ↔ Feedback;
- Selection ↔ Withdrawal;
- Capacity ↔ Schedule;
- Classification ↔ Vocabulary;
- Deliverable ↔ Publication;
- Publication ↔ Archive.

Each side can tell a complete archetypal story without switching purposes midstream.

### Concepts requiring later discipline rather than immediate rejection

#### Controlled Disclosure

The principle is coherent only while focused on **staged withholding/reveal**, not generic permissions.

#### Availability Window

The principle is coherent only while focused on a **visible governed opportunity interval**, not generic time/date functionality.

#### Coverage Target

The principle is coherent only while owning **desired representation**. Actual composition is never its source-of-truth state.

#### Dispatch

The principle is coherent only while focused on **performed operational sends**. Feedback and template-authoring do not belong inside it merely because current email UI combines them.

## 8. Handoff into 001-G

001-G should consolidate discovery rather than immediately begin abstract state/actions.

For each of the 17 surviving candidates, it should decide one of:

- **admit to Phase 002 concept specification**;
- **admit provisionally with an explicit open design question**;
- **defer pending additional product evidence**;
- **reject/demote if cross-candidate consolidation exposes a remaining inconsistency**.

001-G should also freeze:

- the discovery evidence chain;
- the non-concept/derived-behavior register;
- the deferred future concept signals;
- the vocabulary used for the Phase 002 concept baseline.

Only after that gate should the project create canonical concept specifications with purpose, operational principle, abstract state, actions, invariants, and provenance.
